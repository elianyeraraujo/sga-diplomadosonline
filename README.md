# Sistema de Gestión Académica — SGA-DO

Proyecto desarrollado para el Diplomado en Programación.

El sistema permitirá gestionar alumnos, profesores, programas académicos,
notas y certificados.

## Estructura del repositorio

- `docs`: documentación técnica y diagrama UML.
- `python`: implementación del sistema en Python.
- `java`: implementación del sistema en Java.
- `cpp`: implementación del sistema en C++.
